search_centres

GET Request Latency < 50ms

Live Voice Call-la customer kitta irundhu City, Locality, Doctor Specialisation kettu verified hospitals list fetch pannum core engine.

URL: https://oxxy.sharyx.ai/api/v1/Actions/SearchCentres
1

Customer Speech

"Anna Nagar-la dental clinic irukka, discount kedaikkuma?"

2

LLM Function Trigger

search_centres(city="Chennai", locality="Anna Nagar", specialisation="dental")

3

Oxxy DB + Google Fallback

Directory check pannum. Empty-ah irundha Google Maps Places-la irundhu nearby private clinics fetch aagum.

4

Natural Voice Output

"Kandippa sir, Anna Nagar-la Apollo Clinic irukku. Oxxy discount kedaikkum..."

Query Parameters Breakdown

Field Type Status Example / Auto-Synonyms
city string Required Chennai, Delhi, Mumbai, Bengaluru
locality string Optional Anna Nagar, Malviya Nagar, Koramangala
specialisation string Optional dental (teeth, tooth), eye (ophthalmology), general
radius_km number Default 10 5, 10, 20
Important Private-Only Rule: Oxxy Centre Search engine automatically enforces verified=true and is_private=true. Government hospitals are never recommended in voice calls.
